# AI Provider Mistral

Connect Backdrop’s AI features to Mistral models. Mistral can generate text, analyze images, transcribe speech, and extract text and tables from PDFs. Use it for chat, search embeddings, moderation, audio, or document OCR.

## Requirements

Backdrop CMS 1.x, PHP 8.2 or later, and the AI module, plus the Key module.

## Installation

1. Install and enable this module using the official [Backdrop CMS instructions](https://backdropcms.org/user-guide/modules).
2. Open **AI settings** at `admin/config/ai/settings` and enable the provider. Select the service credential you saved with the Key module.
3. Choose a default model for each operation you plan to use.

Read the [module wiki](https://github.com/backdrop-contrib/ai_provider_mistral/wiki) for setup details, supported operations, and troubleshooting.
